# MINTY 小红书视频 · 口播草稿 v1

目标 1:35 左右。一句一个画面（括号里是这句的画面）。英文词照念英文。你录的时候按自己的说法改，改完导出 SRT 给我，画面按 SRT 对时间。

## 开头：直接给结果（0–8 s）

1. 我按住一个键，中英混着跟它说一句话——
   （按住右 Option，面板上的猫竖起耳朵；波形；字幕出现“帮我把这个 component refactor 一下”）
2. 它先回我一句“好，交给它”，然后把活派给了 Claude Code。
   （猫张嘴说话，气泡“好，交给它。”；同时右边 Claude Code 开始干活）

## 为什么做（8–16 s）

3. Claude Code 刚开放 mod，我做的第一个就是它。
   （标题：Claude Code 能装 mod 了；插件列表里出现 minty）
4. 它不只是个桌宠，是一个真的能跟你对话的小助手。
   （猫的五个状态排开，然后收拢成一只）

## 桌宠，只讲一句（16–24 s）

5. 平时它就蹲在对话旁边：听的时候竖耳朵，想的时候歪头，闲着还会打哈欠、舔爪子。
   （在听 / 在想 / 在说 / 打哈欠 / 舔爪，依次切换，一镜到底）

## 动画怎么做的（24–42 s）

6. 动画是用 MiniMax 生成的：拿我家猫的三张照片当参考，每个状态一段三秒的视频。
   （三张猫照片 → 箭头 → 蓝幕视频帧一排）
7. 换动作最怕跳帧，所以每段都用同一张图当第一帧和最后一帧，切的那一下看不出来。
   （首帧 = 尾帧 = 同一张图，中间打哈欠；接缝前后两帧并排）
8. 再抠掉蓝幕、对齐身体，压成动画 AVIF，一段才几十 KB。
   （蓝幕 → 透明；对齐线；“35 KB”）

## 输入：听懂中英混说（42–62 s）

9. 输入用的是本地的 whisper，录音不出电脑。
   （麦克风 → whisper.cpp → 文字，标“本地”）
10. 但我说话是中英混着的，普通的听写会把 React 写成“瑞爱克特”。
    （错误的转写：“那个瑞爱克特的 component 有 bug”，谐音词标红）
11. 所以我做了三件事：给 whisper 一段中英混说的上文，把对话里出现过的英文词提示给它，再用模型把谐音错字改回来。
    （三条清单卡片——值得截图的那张；错词逐个变回 React / refactor / Core ML）

## 先应一声：情绪价值（62–80 s）

12. 我说完以后，两件事同时发生：一边整理成清楚的指令交给 Claude Code，
    （一路分成两路：左边“整理指令 → Claude Code”）
13. 另一边，一个更快的模型先开口回我一句。
    （右边“快脑 · 1 秒”→ 猫说“好，我先去看看”）
14. 就像你跟同事派活，他先说一声“好，我看看”，你就知道他听到了。这一秒的回应，比什么都安心。
    （两个聊天气泡的对比：没回应的已读 vs 一句“好”）
15. 如果只是聊天、问个天气，它自己就答了，不会往 Claude Code 里塞东西。
    （“今天要带伞吗？”→ 猫直接回答，Claude Code 那边没动）

## 输出：念给你听（80–88 s）

16. 活干完了，它把一大段回复缩成一两句话念给我听，英文词照样用英文念。
    （一大段回复 → 缩成一句；波形；“build 过了，三个 test 都通过”）
17. 输入和输出都得能中英混着来，不然它就只是一个会动的贴纸。
    （输入 / 输出两条都标“中英混”）

## 开源（88–95 s）

18. 现在已经开源了，macOS、Windows、Linux 都能装，一条命令。
    （GitHub 页面；三个系统图标；`./setup.sh`）
19. 名字随便起，形象也能换：拿你自家宠物的视频，一条命令就能生成你自己的桌宠。
    （改名“小橘”；换成另一只宠物；结尾卡：minty-voice）
