# 给 Claude Code 的语音助手（macOS）

一个会听、会说、有形象的助手，住在 Claude Code 对话旁边的面板里。**名字、命令、形象动画都由你定**，默认叫 MINTY、是一只猫。

点一下它、或者在任何 App 里**按住右 Option**，中英混着说就行。它会：

1. 用 **sox** 录音，用本地 **whisper.cpp** 转写（离线、免费，针对中英混说调过）
2. **先判断你是要 Claude Code 干活，还是只是在跟它聊天**：
   - 干活（改代码、跑命令、查资料、回答 Claude 的确认……）→ 整理成**清晰的指令**发给 Claude Code，纠正谐音错的技术词（“瑞爱克特”→ React），随口应你一声
   - 聊天、问它看法、问 Claude 做得怎么样、问天气 → **它自己用口语回答，不往 Claude Code 里发**
3. Claude 做完，把回复**总结成一两句话念给你听**

需要：macOS、[Homebrew](https://brew.sh)、Claude Code **v2.1.287 或更新**（终端版或桌面版都行）。

---

## 安装

```bash
git clone https://github.com/alanfeiyuchang/minty-voice.git
cd minty-voice
./setup.sh
```

（也可以在 [Releases](https://github.com/alanfeiyuchang/minty-voice/releases) 下载 zip，解压后运行 `./setup.sh`。装完别删这个文件夹，Claude Code 直接从这里加载它。）

它会一步步问你：

1. **它叫什么**：中文英文都行，比如“小橘”“Jarvis”；再起一个斜杠命令名（只能小写英文），比如 `/xiaoju`
2. **长什么样**：自带的猫、光球，或者**当场用你自己的视频/GIF 做一个**（见下面“换形象”）
3. **按住哪个键说话**：右 Option / 右 Command / 右 Control / Fn，或者不要快捷键
4. **用什么声音、平时说什么语言、听写模型多大**
5. 然后自动装好依赖（sox、whisper.cpp、朗读声音、听写模型）并接进 Claude Code

装完重启 Claude Code，对话旁边就会出现它的面板。输入 `/<你起的命令> check` 确认依赖都是 ✓。

不想回答问题：`./setup.sh --yes` 全用默认值；也可以直接给参数：

```bash
./setup.sh --name 小橘 --command xiaoju --avatar cat --key right-option --model turbo --yes
```

**想改名字、换形象、换声音**：再运行一次 `./setup.sh`，或者在面板里点“⚙ 设置”。
**卸载**：`./setup.sh --uninstall`（设置和你做的形象留在 `~/.claude/minty`，不要了就删掉）。

### 权限

- **麦克风**：第一次录音时 macOS 会问，点“允许”。没弹窗、录音一直失败：系统设置 → 隐私与安全性 → 麦克风，打开 Claude（或你用的终端），然后重启它
- **输入监控**（只有快捷键要）：按住快捷键没反应时，系统设置 → 隐私与安全性 → 输入监控，打开 Claude（或你用的终端），然后重启它

### 隐私

- 录音和转写**完全在你电脑上**，录音文件转写完就删
- 整理指令、念的总结用你的 Claude 额度（默认 haiku，很便宜）
- 默认的神经网络声音（edge-tts）需要联网，**要念的那一两句总结会发到微软的语音服务**。介意的话 setup 时选 macOS 自带的 say（离线）
- 问天气时会请求 wttr.in（它会看到你的 IP，以及你问的城市）

## 怎么用

### 面板

对话旁边是它的面板：上面是形象，下面是它在说的整段话，再下面是“停”和“⚙ 设置”。

- **点形象就开始说，再点一下说完发出**。桌面版的形象是图片、点不了，点它正下方那行字（“点我说话” / “在听…再点一下发送”）；终端里直接点
- 窗口太窄面板放不下时，点输入框上方的按钮（或 `/<命令> panel`）打开
- 形象会跟着状态换动画：待命、在听、在想、等你确认、在说话

### 按住快捷键说话

在任何 App 里**按住快捷键就开始录，松开就发出**。

- 按不到 0.3 秒就松开当误碰；按住时又按了别的键（比如右 Option + 字母打特殊字符）也不算
- 只监听不拦截：这个键照常能用
- 开着好几个会话时，只有**最近用过**的那个会话接这个键（在里面发过消息、点过它的那个）
- 用 Fn 的话，先在 系统设置 → 键盘 里把“按下 🌐 键时”改成“无操作”

### 聊天还是干活

每句话先交给一个快速模型判断：

- 要在电脑上或项目里动手、要查实时信息，或者在回应 Claude 刚提的问题（“好，就这么做”“先别提交”）→ 发给 Claude Code
- 打招呼、闲聊、问常识、问看法、问“它现在在干嘛 / 做得怎么样”（它会看 Claude 最近说的话来答）→ 自己答
- 问天气 → 去 wttr.in 查了自己答（没说地方就用设置里的“城市”，没填就按网络位置猜）
- 拿不准时：会改动东西的当干活，只是问问的当聊天。它答完可能会问一句“要不要让它去做？”，你说“好”，它会把刚才那件事补全了发给 Claude Code

它查不了新闻、股价这类实时信息（会直接告诉你，并问要不要让 Claude Code 上网查）。想要以前那样每句都发：设置里“什么时候发给 Claude Code”选“全部发”。

### 命令

把 `minty` 换成你起的命令名（Claude 工作时也能用）：

- `/minty`：开始 / 结束录音
- `/minty panel`：打开面板
- `/minty settings`：打开设置
- `/minty check`：检查依赖
- `/minty speak`：开关“每条回复都念总结”（默认只念语音发起的那条）
- `/minty stop`：停止录音或朗读

### 横栏界面（可选）

设置里把“界面”换成“横栏”：输入框上方一条，说完**先给你预览**再发。按钮可以点，也可以在空的输入框里只打一个数字：

| 状态 | 按键 |
| --- | --- |
| 待命 | `9` 开关“朗读全部回复” |
| 录音中 | `0` 说完了　`9` 取消 |
| 预览 | `1` 发送　`2` 放进输入框改　`3` 重说　`9` 算了 |
| 朗读中 | `0` 别念了（自己打字发消息也会自动停） |

## 换形象

形象是一个**形象包**：一个文件夹，每个状态一段动画。自带的在 `avatars/`，你自己的放 `~/.claude/minty/avatars/`，设置里的“形象”会列出所有找得到的包。

### 用视频或 GIF 做一个

准备一个文件夹，每个状态放一段动画，**只有 `idle` 是必须的**，缺的状态用 idle 代替：

| 文件 | 什么时候播 |
| --- | --- |
| `idle.mp4` | 待命 |
| `listen.mp4` | 在听你说话 |
| `think.mp4` | 在想 / Claude 在干活 |
| `wait.mp4` | 等你确认（横栏界面的预览） |
| `speak.mp4` | 在说话 |

**待命的变化（可选）**：再放几段 `idle-<随便什么>.mp4`（比如 `idle-yawn.mp4` 打哈欠、`idle-groom.mp4` 舔爪）。平时放 idle，每放 2~4 遍随机插播一段，播完一遍接回 idle。这些片段要**以 idle 的姿势开头、也以它结尾**（做完一件小事回到原样），它们只正着放一遍。自带的猫就有三段：舔爪洗脸、打哈欠、左右张望。

视频格式随意（mp4 / mov / webm / gif…），也可以用装满逐帧图片的文件夹（`idle/0001.png`…）。然后：

```bash
./tools/make-avatar.sh ~/Desktop/my-dog --name "小狗"
```

（第一次要 `brew install ffmpeg libavif uv`；setup.sh 里选“用我自己的动画做一个”会自动装。）

它会：

- **抠背景**：纯色背景（绿幕、蓝幕、白底）自动抠掉；本来就透明的（带 alpha 的 PNG、ProRes 4444、透明 WebM）直接用；背景很杂抠不干净时，整张画面原样放进方框
- **对齐**：每个状态里的主角缩放到一样高、身体中线对准画面中线、脚踩同一条线，切状态时不会忽大忽小、左右跳
- **循环**：默认正放一遍再倒放一遍，素材首尾接不上也不会跳；素材本身就是无缝循环的加 `--loop forward`
- **压缩**：编成动画 AVIF。桌面版一个形象图最多约 90 KB，太大会自动降质量、减帧、缩小

常用参数：`--background keep`（不抠图，做成卡片）、`--seconds 2`（每段只取 2 秒，更清晰）、`--fps 12`、`--out <目录>`。全部参数：`./tools/make-avatar.sh --help`。

### 手工做一个

不用工具也行：建一个文件夹 `~/.claude/minty/avatars/<英文名>/`，放进

- `pack.json`：`{ "name": "显示的名字" }`
- `idle.avif`（必须），以及 `listen` / `think` / `wait` / `speak`、待命的变化 `idle-*.avif`（可选；变化片段在 `pack.json` 里写上 `"durations": {"idle": 6, "idle-yawn": 3}`，单位秒，没写按 idle 6 秒、变化 3 秒算）。格式可以是 `.avif` `.webp` `.gif` `.png` `.svg`，正方形、透明背景最好看，**每个文件不超过 90 KB**

然后在设置里选它。

## 设置

面板里的 **“⚙ 设置”**（或 `/minty settings`）：改完立刻生效。所有设置都存在 `~/.claude/minty/config.json`，setup.sh 和设置面板改的都是它。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 名字 | `MINTY` | 面板标题、它自我介绍都用这个名字 |
| 命令 | `minty` | 斜杠命令名。改完新命令马上能用，旧的重启后消失 |
| 形象 | `cat` | 形象包，或者光球 |
| 什么时候发给 Claude Code | 自动判断 | 自动判断：干活才发；全部发：每句都发（以前的样子） |
| 城市 | 空 | 问天气没说地方时查哪儿；空着按网络位置猜 |
| 界面 | 光球 | 光球：面板 + 右下角小圆圈，说完直接发；横栏：输入框上方一条，先预览 |
| 按住说话的键 | 右 Option | 右 Option / 右 Command / 右 Control / Fn / 关 |
| 朗读回复 | 开 | 关掉后什么都不念 |
| 朗读引擎 | `edge` | `edge`：神经网络声音，自然、需联网；`say`：macOS 自带，离线 |
| 声音 | 晓晓 | 晓晓（女声温和）、云希（男声阳光）、晓伊（女声活泼）、云扬（男声播音腔） |
| 语速 | `+8%` | 相对正常语速，如 `+0%`、`+20%`、`-10%` |
| say 的声音 | `Tingting` | 任何 `say -v '?'` 列出的声音名；edge 用不了时也用它 |
| 模型 | `haiku` | 整理指令、应声、念的总结用的模型 |
| 识别语言 | `zh` | 中英混说用 `zh` 最稳；主要说英文选 `auto` 或 `en` |
| 常用词 | 空 | 你常说、容易被听错的英文词，逗号分隔，如 `Unity, Metal, Core ML` |
| 整理完自动发送 / 放进输入框 | 关 | 横栏界面：跳过预览 |
| Whisper 模型 | `~/.whisper/ggml-large-v3-turbo.bin` | 听写模型文件 |

## 小贴士

- 中英混说时，英文词正常读就行（“帮我把这个 component refactor 一下”）。经常被听错的词填进“常用词”效果最好
- 一次最长录 3 分钟
- 它能在你的电脑上运行程序（sox、whisper、say、pkill、rm），和 Claude Code 本身的权限相同
